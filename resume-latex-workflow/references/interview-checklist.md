# 分阶段资料访谈检查表

正常访谈流程必须逐阶段检查下面的覆盖项，不能仅凭已有简历看起来完整就跳过整个类别。先读已有材料，在 `facts.md` 中将字段记为已提供、待问、明确没有、主动省略；已提供的信息不重复问，“没有这段经历”也算完成覆盖。每轮最多五个短问题，优先补最影响文案的缺口，等待本轮回答后再继续。

这是收集事实与展示选择，不是请用户批准下一步。用户要求直接生成、只改指定批注或跳过某类访谈时执行覆盖，不用检查表重新阻塞已授权工作；未知字段可省略，不能因此虚构经历。用户改变目标或新增事实时，只更新受影响阶段。

## 各阶段必须检查什么

| 阶段 | 主动覆盖的问题 | 最低字段与展示选择 |
| --- | --- | --- |
| 目标与基本信息 | 投什么岗位、实习/校招/社招？联系方式和到岗安排是什么？ | 姓名、电话、邮箱；需要时补城市/主页；到岗时间、实习时长、每周出勤；按用户原话写，不自动填“可协商”。 |
| 教育背景 | 学校、专业、学历与起止时间？是否有适合展示的成绩或排名？ | 毕业年月优先核对；GPA需知道满分制，排名需分母/口径；没有或不展示则省略，不强行添加个人介绍或课程列表。 |
| 工作与实习 | 有没有工作/实习/实验室实践，哪些要展示？ | 单位/团队、岗位、时间；本人负责什么、采取什么方法、解决什么问题、结果及证据；不把团队成果自动写成个人独立完成。 |
| 项目经历 | 展示哪些项目，做到了哪里？本人贡献与核心难点是什么？ | 项目名称、目的/使用场景、时间、技术栈、链接、角色；架构/关键机制、一次具体问题与取舍、验证方法；确认事实稿或授权目标稿，不仅收技术名词。 |
| 荣誉与语言证书 | 有没有竞赛、奖学金、英语四六级或其他相关证书？哪些想写？ | 竞赛年份/届次、全名、站点或组别、奖项/名次、团队或个人；奖学金级别/名称；证书是否通过、分数是否希望展示。级别字段按资料核对，未知不猜。 |
| 专业技能 | 哪些真正用过、各自熟练到什么程度，能对应什么经历？ | 语言/工程、系统与中间件、基础与分析能力；保留用户指定原句；不要从组件清单推断“精通”。允许时再问想学未学方向，明确不要时不添加。 |
| 参考与交付偏好 | 有参考简历/照片吗，偏好的字体配色、模块顺序、页数和文件位置是什么？ | 复用会话已有偏好；说明参考要借鉴内容、版式还是二者；照片、项目角色、级别栏和联系方式布局按明确选择，不照搬参考作者信息。 |

## 提问示例

只用尚未覆盖的项，不把下面示例整套发给用户。

- 基本信息轮：“目标是实习还是校招、主要投什么岗位？到岗时间、连续时长和每周出勤分别怎么写？”
- 教育轮：“学校/专业/学历和毕业年月是什么？是否展示 GPA 或专业排名，有的话满分或排名总人数是多少？”
- 经历轮：“挑一项你负责的改动：当时遇到了什么问题，你设计了什么方案，最后实现了什么功能或效果？如果做过测试，测了哪些场景，有能核对的结果吗？”
- 荣誉轮：“有哪些竞赛或奖学金希望写？请给赛事名、年份、组别和奖项/名次。英语四六级是否通过，是否想展示，分数要不要写？”
- 技能轮：“你最有把握的技术有哪些，分别在哪个项目用过？有没有必须保留的能力表述？”
- 交付轮：“参考主要借鉴内容深度还是版式？字体、配色、模块顺序和输出位置有偏好吗？”

## 进入制作的检查

每个适用阶段应有资料或明确跳过记录。仍有必要缺口时，先定向补问，不直接交出一份让用户逐项提醒“这块为什么没写”的稿子；同一事实最多追问两轮，仍不清楚就省略或按用户指定占位。对“已有简历直接改”只检查本次相关缺口，不重启全部访谈。

英语证书只证明相应证书事实；英文题面/资料阅读经历可支撑专业英语阅读能力，不自动支持口语流利、商务沟通或写作熟练。原句保留要求、对照示例和最终修改都要在成品文字中复核。
