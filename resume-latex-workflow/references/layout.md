# 当前模板的版式约定

A4单页，左右边距0.65英寸，上下0.50英寸。中文优先微软雅黑，缺失时使用Noto Sans CJK SC或FandolHei；英文优先Times New Roman，缺失时TeX Gyre Termes。正文10pt，章节12pt蓝灰色，标题下有细线。

基本信息左侧按组排列，右侧照片宽度约占正文18%；姓名22pt，求职方向及城市一行，邮箱电话一行，GitHub/主页一行，到岗安排一行。联系方式过长时允许换行，避免挤入照片区。无照片则改为整行宽度。教育学校/专业在左、时间在右，排名与奖学金紧随其后。

项目名称与语言/技术栈12pt加粗，链接11pt放同一行右侧，不另开“项目地址”行。链接用可读的仓库短路径，实际URL保持完整；若文字过长，优先精简标题与标签，必要时用两个minipage控制左右宽度，不能让链接覆盖标题。语言可按用户偏好写Go或Golang。

项目正文：一句背景/目的，2～4条实现与问题解决，一句有证据的验证结果。验证结果保持正文大小，第二项目标题不要为醒目而额外放大。第二项目预留空白仅在用户明确要求时保留。

竞赛荣誉位于技能之上；奖项名称、等级和名次条目末尾不加句号，右侧级别前也不加句号。奖项级别右对齐，但具体省级/国家级归类由资料或用户确认，不一概推断。Codeforces等账号适合放在荣誉首行并链接到主页；分数说明当前/最高，无法核验时不要擅自转换用户提供分数的含义。

技能用完整、简洁的句子，避免孤立词堆砌及重复Linux等术语。技能熟练度与事实对应，待学习项显式标注。占位字段默认待补充，可按用户要求使用橙色XXXX。

## 编译与验证

原生LaTeX编辑器可用时打开保存的源文件，并使用原生编译功能；否则在源码目录执行 `xelatex -interaction=nonstopmode -halt-on-error resume.tex`，目录/文件含空格时正确引用路径。为目录、引用或书签所需运行第二次；不要无意义地重复编译。

检查日志中的Overfull和Missing character，逐项修复；Underfull结合实际渲染判断。确认PDF文字可选、字体嵌入、链接正确，逐页查看。低分辨率预览不能作为PDF模糊的证据；可渲染约216dpi预览，必要时另做局部高清图。不得声称检查通过而没有实际运行与查看。

模板仅复现已接受的排版参数，使用标准article自行实现，不依赖第三方resume.cls或个人字体文件。此前设计参考： https://github.com/flamingoTOM/Auto-CV 。
